# Voice to File - Flutter Android App

App Android in Flutter che ascolta dal microfono, trascrive la voce in testo e salva il risultato in formato `.txt` o `.pdf`, facilmente condivisibile o apribile su PC.

---

## 🚀 Come ottenere l'APK tramite GitHub Actions in 3 passaggi

1. **Crea una nuova repository su GitHub**:
   * Vai su [github.com/new](https://github.com/new).
   * Assegna un nome (es. `voice-to-file-app`) e impostala come **Public** o **Private**.

2. **Carica questa cartella nella repository**:
   * Da terminale dentro questa cartella esegui:
     ```bash
     git init
     git add .
     git commit -m "Initial commit"
     git branch -M main
     git remote add origin https://github.com/TUO-USERNAME/NOME-REPO.git
     git push -u origin main
     ```
   * *Oppure trascina semplicemente i file tramite l'interfaccia web di GitHub.*

3. **Scarica l'APK compilato**:
   * Vai nella scheda **Actions** della tua repository su GitHub.
   * Vedrai il workflow **"Compila APK Android"** in esecuzione automatica.
   * Al termine (circa 2-3 minuti), clicca sulla run completata e in basso sotto **Artifacts** troverai `voice-to-file-app-release.zip`.
   * Estrai il file `.zip` per ottenere il file `app-release.apk` pronto da installare sul telefono Android!
